Python Developer Assessment

This repository contains my work for the Python Developer Assessment Program. I used this project to practice Python, Git and GitHub, code formatting, data structures, OOP, error handling, debugging, and working with an API.

Completed Tasks

Task 1.1 - Python setup and Hello World

Task 1.2 - Git and GitHub basics

Task 1.3 - Code style and linting

Task 2.1 - Data structures and algorithms

Task 2.2 - Object-oriented programming

Task 2.3 - Error handling and debugging

Task 3.1 - Basic API interaction

Task 3.2 - Final project submission

Files

hello.py - Hello World program

bad_style.py - Code style and linting task

dsa_challenges.py - Data structures and algorithm functions

book_store.py - Book class and OOP task

debug_errors.py - Error handling and debugging task

api_client.py - API request and user information task

How to Run

Open the terminal in the project folder and run the Python files using:

python hello.py
python bad_style.py
python dsa_challenges.py
python book_store.py
python debug_errors.py
python api_client.py


The API task uses the requests library. If it is not installed, run:

python -m pip install requests


I also used Black and Flake8 for code formatting and checking code style.
